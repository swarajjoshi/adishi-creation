# ADISHI CREATION: Phase 1

1. Install Node.js 20 LTS (https://nodejs.org), then restart VS Code.
2. Open this folder in VS Code (File > Open Folder), then Terminal > New Terminal.
3. Run `npm install`
4. Copy the official logo to `public/brand/adishi-logo.png`
5. Run `npm run dev` and open http://localhost:3000
